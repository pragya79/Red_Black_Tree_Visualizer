Red-Black Tree properties


Refer to: Introduction to Algorithms — Cormen, Leiserson, Rivest & Stein (CLRS)
  1. 01
    Node colors

    Every node is red or black.

  2. 02
    Black root

    The root is always black.

  3. 03
    No adjacent red nodes

    A red node cannot have a red child.

  4. 04
    Equal black height

    Every path from a node to its descendant NIL leaves has the same number of black nodes.

  5. 05
    Binary search ordering

    Left values are smaller and right values are larger.
